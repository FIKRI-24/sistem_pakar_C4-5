2. Rincian Tahapan Alur Kerja Sistem

1

Pelatihan Model C4.5

Admin/Guru BK mengimpor 200 data alumni. Mesin Python C4.5 menghitung Entropy & Gain Ratio untuk membangun Pohon Keputusan.

2

Pengisian Kuesioner

Siswa mengisi 16 butir kuesioner psikotes terpadu untuk 3 jurusan (TKJ, DPIB, K3R) mencakup Minat, Bakat, Kepribadian & Nilai.

3

Penyimpanan Per Butir

Setiap butir soal dan pilihan jawaban siswa tersimpan rinci ke tabel hasil_tes_jawabans untuk transparansi bimbingan BK.

4

Klasifikasi Pakar C4.5

Atribut siswa ditelusuri di cabang Decision Tree untuk menghasilkan Rekomendasi Karir Utama & Matched Rule terpercaya.

5

Cetak Laporan PDF

Laporan dicetak ber-Kop Resmi Kedinasan Kemendikbudristek & SMKN 1 Hiliran Gumanti lengkap dengan lembar pengesahan tanda tangan.

                sequenceDiagram
                    autonumber
                    actor Siswa as Siswa SMKN 1 Hiliran Gumanti
                    participant Web as Web Laravel (Frontend/Backend)
                    participant DB as MySQL Database
                    participant Py as Python FastAPI C4.5 Engine

                    Siswa->>Web: 1. Kirim Jawaban Kuesioner Psikotes (16 Soal)

                    Web->>Py: 4. POST /classify (Kirim Atribut Siswa)
                    Py->>DB: 5. Fetch Active Decision Tree Structure
                    Py->>Py: 6. Traverse Pohon Keputusan C4.5 & Match Rules
                    Py-->>Web: 7. Return Karir Terpilih, Kecocokan (%), & Rule Matched
                    Web->>DB: 8. Simpan Rekomendasi Karir Siswa (`rekomendasi_karirs`)
                    Web-->>Siswa: 9. Tampilkan Hasil Rekomendasi & Cetak PDF Laporan
